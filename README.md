# Closet 試衣間

在瀏覽器裡跑的寫實女性 3D 試衣假人，可以：

- **自訂身形**：輸入身高、體重、胸圍、腰圍、臀圍等尺寸，模型會實際量測並自動調整到誤差 1.5cm 以內；也可以上傳全身照，自動估算尺寸。
- **擺姿勢**：站姿、坐姿（附椅子，裙擺會自然垂落）、半身特寫，並可自動 360° 旋轉。
- **試穿照片中的衣服**：上傳衣服照片後，系統會去背、判斷版型（上衣／洋裝／裙子／長褲、袖長），再把照片貼到依尺寸生成的 3D 衣服上。
- **判斷合不合身**：貼上網路商品的尺寸表和材質說明，系統會逐部位判斷「過小／偏緊／合身／寬鬆／過大」並推薦尺碼，3D 畫面也能顯示鬆緊分布。
- **穿搭建議**：依三圍比例判斷體型（沙漏、梨型、蘋果、H 型、倒三角），給出推薦單品、領口與避免事項；也可以用本機的 Claude Code 訂閱登入問 AI。

## 安裝（第一次）

需要 Node.js 20 以上，以及 Python 3（含 `numpy`、`pillow`）。

```bash
npm install
npx playwright install chromium   # 只有跑驗收測試才需要
npm run setup                     # 下載 CC0 素材、轉出假人模型、下載姿勢偵測模型（約 300MB，只需一次）
```

## 使用

```bash
npm run dev        # 開啟 http://localhost:5391
npm run bridge     # （選用）另開一個終端機，啟動 AI 穿搭建議中繼
```

1. **身形**分頁：填入尺寸 →「套用到假人」。下方表格是假人**實際量到**的數字。
2. **試穿**分頁：上傳衣服照片（白底商品照效果最好）→ 確認類型 →「穿上」。沒有照片時可以用純色試穿。
3. **尺寸**分頁：從購物網站複製尺寸表和材質貼上 →「分析尺寸」。點尺碼按鈕可以切換試穿不同尺碼，勾選畫面上的「鬆緊分布」可以看到哪裡緊、哪裡鬆。
4. **穿搭**分頁：看體型判斷與建議；按「問 AI」會透過本機 `claude -p` 回答（需要先 `npm run bridge`，並且已經登入 Claude Code）。沒有啟動中繼時，可以按「複製提示詞」貼到 claude.ai。

## 技術說明

| 部分 | 做法 |
|---|---|
| 假人模型 | [MakeHuman](http://www.makehumancommunity.org/) 1.x 基礎網格、體型 target、骨架、權重、髮型、皮膚（全部 CC0），由 `tools/build_avatar.py` 轉成 `public/avatar/avatar.json + .bin` |
| 身形求解 | 在模型上水平切片、取凸包周長（模擬皮尺），用 Gauss-Newton 反推 64 組 morph 權重（`src/avatar/solver.ts`） |
| 姿勢 | MakeHuman BVH 姿勢＋程式產生的坐姿（依世界方向對準骨頭），CPU 蒙皮 |
| 衣服 | 依成衣尺寸生成：身體表面裁切＋凸包撐開到成衣圍度＋垂落＋Taubin 平滑模擬布料張力；裙擺用圓錐布片加摺痕；坐姿時用 PBD 布料模擬（`src/garment/`） |
| 照片 | 衣服照片：邊緣色彩洪水填充去背、鄰近色擴散貼圖。人像量身：MediaPipe Pose Landmarker＋人像分割 |
| 合身判斷 | 尺寸表解析（中／英、平量／圍度、吋／公分、彈性範圍）＋材質彈性係數＋逐部位鬆份規則（`src/fit/`） |
| 繪圖 | three.js（PBR 材質、環境光、陰影、ACES 色調） |

## 限制

- 純瀏覽器方案，逼真度比不上雲端 AI 試穿（照片級生成）。衣服背面花色是由正面推測的。
- 照片量身在合成測試中，只用正面照誤差約 ±4.5cm，加側面照約 ±2.5cm；實際照片會受姿勢、衣物鬆緊影響。
- 衣服版型目前有上衣、洋裝、裙子、長褲四類。

## 開發

```bash
npm test            # 單元測試（vitest）
npm run verify      # 完整驗收：型別檢查＋建置＋單元測試＋AI 中繼＋瀏覽器 E2E（截圖在 _artifacts/）
node tools/photo-selftest.mjs   # 用假人截圖驗證照片量身準確度（需先 npm run dev）
```
