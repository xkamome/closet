# Closet 試衣間

在瀏覽器裡跑的寫實女性 3D 試衣假人，可以：

- **自訂身形**：輸入身高、體重、胸圍、腰圍、臀圍等尺寸，模型會實際量測並自動調整到誤差 1.5cm 以內；也可以上傳全身照，自動估算尺寸。進階微調可以調整臉型（亞洲／歐美／非洲混合）、肌肉、小腹、臀部、胸型等，外觀可換膚色與 5 種髮型、髮色。
- **擺姿勢**：站姿、坐姿（附椅子，裙擺會自然垂落）、半身特寫，並可自動 360° 旋轉。
- **試穿照片中的衣服**：可以上傳商品平拍照，也可以上傳模特兒穿著的全身照。系統會切出衣服、判斷版型（上衣／洋裝／裙子／長褲、袖長、衣長），再把照片依身體關節對位，貼到依尺寸生成的 3D 衣服上；上衣和裙子可以一起穿。
- **衣櫃**：試穿過的衣服（含照片、尺寸表、選定尺碼）可以收藏在瀏覽器裡，之後一鍵再穿。
- **判斷合不合身**：貼上網路商品的尺寸表和材質說明，系統會逐部位判斷「過小／偏緊／合身／寬鬆／過大」並推薦尺碼，3D 畫面也能顯示鬆緊分布。
- **穿搭建議**：依三圍比例判斷體型（沙漏、梨型、蘋果、H 型、倒三角），給出推薦單品、領口與避免事項；也可以用本機的 Claude Code 訂閱登入問 AI。

## 呈現模式（3D 計算、2D 呈現）

畫面左上角的「呈現」可以切換：

| 模式 | 說明 |
|---|---|
| 3D（可旋轉） | 原本的即時 3D，可旋轉、坐下 |
| 寫真 | 站姿正面的精緻照片感（工具列「雙腳」滑桿可以把雙腳併攏）：衣服依版型與重力懸垂生成，照片依領口、肩點、腋下、下擺對位，含環境光遮蔽與地面陰影 |

「下載圖片」可以存成 PNG。穿搭比較頁在 `http://localhost:5391/lab.html`（`npm run dev` 時）。程式在 `src/look/`。

## 衣櫃、U牌標準尺寸、紮衣服

- 衣櫃一開始就有預設衣服，以及 22 件 U牌素色基本款（內衣、上衣、洋裝、長裙、運動）。U牌款的尺寸表與「適合身形範圍」取自該品牌官網（日本站＝台灣尺碼；日本沒賣的 5 件用美國站，標示「美版」），穿上時依你的胸腰臀自動選尺碼（★），可以在「身上的衣服」換尺碼和顏色。
- 「一鍵穿搭」：瑜伽、跑步、健身、休閒運動、喇叭褲運動、長裙日常、層次長裙。
- 上衣配裙子或褲子時，可以按「紮進去／放出來」。
- 「用文字生出衣櫃」：描述想要的衣服或衣櫃風格（例：上班通勤的膠囊衣櫃，大地色系），選件數後生成。有開 `npm run bridge` 時由 Claude 設計，沒開時用關鍵字判斷；尺寸依最接近的 U牌基本款。
- 「身形」分頁的「我的假人」可以儲存／讀取／匯出／匯入假人特徵（三圍、體型微調、膚色、髮型、自拍、雙腳距離）。

## 我的臉

「身形」分頁最下面的「我的臉」可以上傳一張正面自拍：五官會貼到假人臉上，並自動調整膚色、眼睛顏色、髮色和最接近的髮型（之後可以在「外觀」手動改）。「相似度」滑桿調整貼上的強度。3D 和寫真都看得到。照片只存在這個瀏覽器，不會上傳。臉部偵測使用 MediaPipe Face Landmarker（`npm run setup` 會下載）。

## 安裝（第一次）

需要 Node.js 20 以上，以及 Python 3（含 `numpy`、`pillow`）。

```bash
npm install
npx playwright install chromium   # 只有跑驗收測試才需要
npm run setup                     # 下載 CC0 素材、轉出假人模型、下載姿勢偵測模型（約 300MB，只需一次）
```

## 使用

```bash
npm run dev        # 開啟 http://localhost:5391
npm run bridge     # （選用）另開一個終端機，啟動 AI 穿搭建議中繼
```

1. **身形**分頁：填入尺寸 →「套用到假人」。下方表格是假人**實際量到**的數字。
2. **試穿**分頁：上傳衣服照片 → 確認類型 →「穿上」。模特兒照若同時偵測到上衣和下身，點選上方的按鈕分別穿上。沒有照片時可以用純色試穿。按「收進衣櫃」保存。
3. **尺寸**分頁：從購物網站複製尺寸表和材質貼上 →「分析尺寸」。點尺碼按鈕可以切換試穿不同尺碼，勾選畫面上的「鬆緊分布」可以看到哪裡緊、哪裡鬆。
4. **穿搭**分頁：看體型判斷與建議；按「問 AI」會透過本機 `claude -p` 回答（需要先 `npm run bridge`，並且已經登入 Claude Code）。沒有啟動中繼時，可以按「複製提示詞」貼到 claude.ai。

## 技術說明

| 部分 | 做法 |
|---|---|
| 假人模型 | [MakeHuman](http://www.makehumancommunity.org/) 1.x 基礎網格、體型 target、骨架、權重、髮型、皮膚（全部 CC0），由 `tools/build_avatar.py` 轉成 `public/avatar/avatar.json + .bin` |
| 身形求解 | 在模型上水平切片、取凸包周長（模擬皮尺），用 Gauss-Newton 反推 64 組 morph 權重（`src/avatar/solver.ts`） |
| 姿勢 | MakeHuman BVH 姿勢＋程式產生的坐姿（依世界方向對準骨頭），CPU 蒙皮 |
| 衣服 | 依成衣尺寸生成：身體表面裁切＋凸包撐開到成衣圍度＋垂落＋Taubin 平滑；**接袖**（袖籠依肩寬定位、袖管沿手臂橫切面撐開袖寬、依重力下垂）、**打版式領口曲線**（圓領／V／U／一字的前後領深與領寬）＋羅紋包邊；裙擺用圓錐布片；最後以 PBD 布料放鬆（重力、不可伸長、彎曲、碰撞含內層衣物），換衣服 1 秒內完成。比例以 MakeHuman CC0 專業女裝校正（`src/garment/`） |
| 照片 | 商品照：邊緣色彩洪水填充去背、鄰近色擴散貼圖。模特兒照：MediaPipe 多類別分割（衣服／皮膚／頭髮）＋姿勢關節，拆分上衣／下身／洋裝並依關節分段對位貼圖。人像量身：Pose Landmarker＋人像分割 |
| 合身判斷 | 尺寸表解析（中／英、平量／圍度、吋／公分、彈性範圍）＋材質彈性係數＋逐部位鬆份規則（`src/fit/`） |
| 繪圖 | three.js（PBR 材質、環境光、陰影、ACES 色調、GTAO 環境光遮蔽） |

畫面左上角的「高畫質」會開啟環境光遮蔽（皺褶與衣物邊緣的陰影）；電腦太慢時會自動關閉。

## 限制

- 純瀏覽器方案，逼真度比不上雲端 AI 試穿（照片級生成）。衣服背面花色是由正面推測的。
- 照片量身在合成測試中，只用正面照誤差約 ±4.5cm，加側面照約 ±2.5cm；實際照片會受姿勢、衣物鬆緊影響。
- 衣服版型目前有上衣、洋裝、裙子、長褲四類。

## 網路版

`npm run build:web` 會在 `dist-web/` 產生可以直接放上網的靜態網站（不含「問 AI」和「用文字生出衣櫃」，因為它們需要本機的 AI 中繼）。所有資料（自拍、衣櫃、假人）都只存在使用者自己的瀏覽器。`node tools/check-web.mjs` 會用 `/closet/` 子路徑檢查建好的網站。

## 開發

```bash
npm test            # 單元測試（vitest）
npm run verify      # 完整驗收：型別檢查＋建置＋單元測試＋AI 中繼＋瀏覽器 E2E（截圖在 _artifacts/）
node tools/photo-selftest.mjs   # 用假人截圖驗證照片量身準確度（需先 npm run dev）
```
